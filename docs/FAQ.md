# 常见问题

## 下载后怎么没有游戏窗口

这是供 AI 使用的 Skill 资料包。先让支持它的智能体读取指令，再提出需求。附带的工程模板需要对应环境运行，下载 ZIP 本身不会启动游戏。

## 为什么没有自动生图

检查智能体是否真的有图像工具，以及本次是否要求制作。没有工具时可以拿到提示词和交接要求；只有视频工具不可用时，也不必把图片制作一起停掉。

## 为什么默认先给方案

这是新项目的默认工作方式。明确说“直接实现”“先搭骨架”即可按需求推进。局部修复不应重走完整策划。

## 模板会不会限制玩法

所有资料都可裁剪或跳过。直接说明你自己的机制，让智能体围绕它选择结构。附带点击模板只用于演示常见状态与输入处理。

## Skill 没被识别

确认技能目录里直接有 `SKILL.md`，并检查当前工具支持的安装位置。ZIP 解压后多套一层文件夹很常见。必要时重新开启会话，或明确让智能体读取文件。

## 资产检查脚本不接受我的字段

脚本支持的是本包示例格式。你可以使用另一套资产结构，改工具或换验证方法，不必把项目改成示例的样子。

## 项目创建脚本说文件夹已经存在

换一个新目录，或让智能体分析现有工程后只移植需要的内容。脚本会保留已有项目，毕竟谁也不想用一个新圆圈换掉半个月的劳动成果。

## 可以直接认定它做出的游戏已经能发布吗

先看实际验证记录。代码测试、浏览器试玩、设备测试和商店审核是不同环节。缺少哪个就如实记录，再按发布目标补齐。

## 想反馈问题

请提供需求原文、使用的模型或工具、预期行为和实际结果。涉及代码时附最小复现，涉及创意时说明哪个决定被改偏了。提交前去掉 API 密钥、账号凭据和私人素材。
