# 复制一句，开始做

下面是需求示例，内容可以任意改。它们没有预订你的创意名额。

## 想先聊聊

```text
使用 $casual-light-game-studio。
想做一个轻松的整理小游戏，物件之间有故事联系。
先给几个有区别的体验方向，我选完再细化。
```

## 想马上玩起来

```text
使用 $casual-light-game-studio。
做一个浏览器里的接雨滴小游戏，用鼠标移动杯子。
直接实现最小可玩版，先用几何图形，能开始、结束和重玩就行。
技术按这个目标推荐，别为了用模板改我的玩法。
```

## 完全没有胜负也行

```text
使用 $casual-light-game-studio。
我想做一个用鼠标吹动云朵的小品，没有分数和失败。
先验证云的移动与反馈是否舒服，暂时不加关卡。
```

## 让外部模型帮忙

```text
使用 $casual-light-game-studio。
我的场景风格已经确定，需要三种物件和一段结尾视频。
先读现有美术约定，再给生成提示词、规格和回传要求。
当前只有文本能力，不要声称已生成素材。
```

## 今天只改一个地方

```text
使用 $casual-light-game-studio。
现有项目里触屏点击一次会计分两次。
只排查并修复这条输入链路，完成后验证鼠标和触控。
```

## 我改主意了

```text
使用 $casual-light-game-studio。
保留原来的技术和美术，玩法从限时挑战改为自由探索。
先分析受影响的规则与界面，更新接续记录，等我要求再改代码。
```

## 给世界取一套合适的称呼

```text
使用 $casual-light-game-studio。
我的游戏是幽灵邮局，玩家夜间送信，有委托和路线，没有战斗、等级或体力。
请直接设计身份称呼、任务列表、路线菜单和首轮教学，温柔但有一点夜班幽默。
说明命名理由，区分候选和采用稿，不要增加玩法；缺少的信息标明假设。
```

## 只改三个词

```text
使用 $casual-light-game-studio。
这是阳台茶摊经营游戏，只给订单、金钱、顾客关系各想一个叫法。

```

## 已有文案打架了

```text
使用 $casual-light-game-studio。
我的任务奖励里“余烬”是货币，角色面板里“余烬”却是经验。
保留货币名称，检查混淆并提出经验名称，列出需要同步修改的文案位置。
只给建议，不改代码、资源路径和存档字段。
```

## 安静一点也好

```text
使用 $casual-light-game-studio。
游戏只有鼠标拖动色带、滚轮调风速，没有角色、关卡和胜负。
请写两句操作提示，以及重置画面、声音设置、退出三个按钮的文字。
保留容易理解的普通词，不要加剧情或养成系统。
```
