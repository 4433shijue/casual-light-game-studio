# 复制一句，开始做

下面是需求示例，内容可以任意改。它们没有预订你的创意名额。

```text
使用 $casual-light-game-studio。
想做一个轻松的整理小游戏，物件之间有故事联系。
先给几个有区别的体验方向，我选完再细化。
```

