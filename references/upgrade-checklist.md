# A 到 B 到 C 的升级清单

> 使用定位：本资料仅供启发与按需取用，可改写、组合或跳过。用户与智能体的创意决定方案；示例类型、数值、流程和结构不构成创作限制。技术操作的真实前提、执行授权与验证诚实性仍需遵守。

## 从 A 到 B

- 当前体验结构已得到相应验证，新增内容不会掩盖未解决的问题。
- 按展示需求补充启动、教学、UI 和反馈；仅在作品具备失败或重玩时完善对应体验。
- 明确展示时长、演示路径和可替换占位资产。
- 检查窗口尺寸、输入、音量、加载和第一次运行。

## 从 B 到 C

- 目标内容量已明确，关卡、成长和模式只选作品需要的部分。
- 需要的数据、设置、平台交付和性能预算有方案，存档按实际需求加入。
- 资产生产有批次、命名、版本和回滚方式。
- 补充异常流程、无障碍、设备适配、发布包和验收记录。

## 每次新增内容

记录新增目标、改动模块、数据兼容、资产需求、风险、回归测试和结果。若新增内容需要改动核心规则，先更新体验结构或核心循环及验收标准，再实现内容。
