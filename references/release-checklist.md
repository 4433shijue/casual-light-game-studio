# 从原型到发布的检查清单

> 使用定位：本资料仅供启发与按需取用，可改写、组合或跳过。用户与智能体的创意决定方案；示例类型、数值、流程和结构不构成创作限制。技术操作的真实前提、执行授权与验证诚实性仍需遵守。

## 可玩性

- 第一次启动能到达可玩状态。
- 玩家知道目标、输入和当前反馈。
- 作品实际具备的成功、失败、暂停、退出和重玩路径能到达，无目标作品不为检查清单增加状态。
- 重玩不会继承不该继承的临时状态。

## 内容与资产

- 已确认资产与候选资产分开。
- 没有缺失、错层、黑底、拉伸、错误锚点或不可读文本。
- 外部生成资产有来源和许可记录（若用户提供）。
- 资产目录、命名和导入设置可复现。

## 平台与性能

- 在目标分辨率和输入设备上运行过。
- 记录启动时间、加载失败、帧率或明显卡顿。
- 窗口、全屏、方向、音量和退出行为符合目标平台。
- 失败时有可理解的提示和恢复路径。

## 发布与回归

- 版本号、变更记录和构建产物名称明确。
- 从干净目录或新用户状态启动过一次。
- 关键路径在每次增量更新后重新检查。
- 未验证的平台、账号、联网服务和商店流程明确列出。

## 浏览器与屏幕方向

- 按承诺验证文件直接打开、本地服务或网站访问，说明实际需要的工具。
- 离线交付检查资源依赖并验证断网运行；不能只数 HTML 文件。
- 横屏或竖屏按目标范围测试，支持旋转时检查状态、布局与命中坐标。
- 检查控件遮挡、文字换行和输入可达；模拟触控与真实设备结果分开写。
- 音频、存档、全屏等按实际使用的功能检查，不为填表添加能力。

需要整理介绍、录屏方案或给朋友使用的启动说明时，参考 [作品展示与交付](showcase-and-delivery.md)。只描述已实现内容，外部发布按实际授权执行。
