# 游戏文案工作室 · Game Copywriting Studio

首次独立发布，版本 v1.2.0。可以给角色想称呼、给按钮写提示，也能让同一个角色面对不同人说出合适的话。只改一句也欢迎，不用先提交世界编年史。

将完整 game-copywriting-studio 文件夹放入你的智能体支持的技能目录，按工具方式重新加载。也可让智能体直接读取本目录的 SKILL.md。无需安装小游戏工作室、写作 Skill 或运行 Python。

```text
使用 $game-copywriting-studio。
茶叶不足时不能制作饮料，变量 {missing} 表示缺少的片数。
给我首次解释和重复出现的短提示，保留变量，不增加玩法。
```

更多用法见 [用户指南](USER_GUIDE.md)。共享方法和案例位于本包 references 与 assets 中，复制时请带齐。创意你来定，模板可以跳过。

不同模型的理解、风格和工具能力存在差异，同一模型多次生成也可能不同。措辞可以变化，用户要求、已确认术语和实际机制仍须保持。测试只代表所记录场景，不保证所有模型相同效果。

维护者通过主仓库 scripts/build_copywriting_skill.py 同步共享资料，本包内共享副本不手工维护。安装用户不需要执行这个脚本。原项目暂未指定开源许可证。
